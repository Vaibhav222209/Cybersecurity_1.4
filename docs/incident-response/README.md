# Incident response — Phase 6 planned

Deliver an incident plan and playbooks for phishing, ransomware, simulated fraud, DDoS, and insider misuse. Define triage, ownership, containment authorization, evidence preservation, communications, recovery, and lessons learned. SOAR-style account-lock/token-revocation scripts must default to dry-run against synthetic local identities and require explicit scope for changes.

Reporting duties, including the Swiss critical-infrastructure cyberattack reporting window, require verified scope, trigger, recipient, and timing references. Do not imply every alert is reportable. Use tabletop scenarios with invented actors and no operational attack steps.
