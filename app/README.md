# Demo API — Phase 2 planned

Implement a minimal Python 3.12 FastAPI application using synthetic, non-routable accounts. Planned endpoints cover authenticated account views and simulated payments with ownership checks, bounded input, replay/idempotency handling, and redacted audit events.

Acceptance requires functional API tests, negative authentication/authorization tests, secure JWT validation, resource limits, and readiness through the local TLS proxy. No API or dependencies are implemented in Phase 1. See the [architecture](../docs/architecture.md).
